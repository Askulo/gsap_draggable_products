# Interactive Draggable Product Viewer

This is a front-end project showcasing an interactive product grid with a dynamic drag-and-drop feature. The demo features a grid of vases that can be seamlessly dragged by the user. Selecting a vase transitions the view to display a detailed product description and an add-to-cart interface.

---

### Features

* **Interactive Grid:** A responsive grid layout that allows for a fun, hands-on user experience.
* **Drag-and-Drop:** Uses the GSAP Draggable plugin to enable smooth, intuitive movement of items within the grid.
* **Dynamic Product View:** Clicking or dragging an item brings up a clean, slide-out view with product details and purchase options.
* **Clean UI/UX:** A minimalist design that focuses on the product and the interactive experience.

---

### Technologies Used

* **HTML5** & **CSS3**
* **JavaScript**
* **GSAP (GreenSock Animation Platform):** The core animation library, specifically the `Draggable` plugin, which powers the interactive movement.

---

### Setup and Usage

To run this project locally, simply follow these steps:

1.  Clone the repository:
    `git clone [repository-url]`
2.  Navigate into the project directory:
    `cd [project-folder]`
3.  Open the `index.html` file in your preferred web browser.

For best results and to avoid any CORS issues, it's recommended to run a simple local web server (e.g., using VS Code's Live Server extension or Python's `http.server`).
